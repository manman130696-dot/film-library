# 满的公开片库

[打开片库](https://manman130696-dot.github.io/film-library/)

影像片段、拉片分析、包装动效设计和制作提示词。

支持 Vlog、视觉动效、纪录片、剧情短片、审美短片、综艺包装、商业与音乐影像、知识解说。品牌广告和音乐影像合并为「商业与音乐影像」。一部作品可属于多个分类，分类筛选可与搜索、用途标签和分析状态组合使用，手机端也可筛选。

## 部署

GitHub Pages 选择 Deploy from a branch、main、/(root)。

请同时保留根目录的 `index.html`、`archive-loader.js`、`categories.json` 与 `film-library-public/index.html`，不能只上传单个首页。首页从原始归档读取预览、封面、分析与提示词，再应用新的分类。

`archive-loader.js` 内的分类配置与 `categories.json` 应同步修改；后者也用于自动检查。检查只读取仓库，不提交或推送内容。

City Ride、认知差和秋游提供完整预览，其余 11 部仅提供前 10 秒预览；其他影片的完整原片未全部上传。未完成的分析和声音听辨保留原状态。公开版不含本机原片路径或私人联系信息。

## 创作资源

桌面侧栏和手机导航新增独立的「动效工具」入口：[`tools.html`](https://manman130696-dot.github.io/film-library/tools.html)。

目前收录「开场实验室」可替换动效模板及使用说明。模板下载链接指向 ChatGPT 中的文件，需要登录有访问权限的账号；不改变文件的原有权限。工具页面不加载影片归档，不计入视频或案例数量。

City Ride 已经用户确认公开：172 秒完整预览、原片、114 个镜头的关键帧和人物参考截图。声音仍待试听；分析中保留未确认范围。

## 包装设计辅助版

现有片库导航和动效工具页提供 `packaging.html` 入口。投入本机视频，选择本片范围；按关键词和用途浏览实际可播放的包装对标，可加入最多三个候选方向，选择后编辑当前片段的理解作用、趣味点、构图、元素和运动。确认当前方案后才输出制作提示词，修改后需重新确认。

当前为辅助版：自动画面理解、自动推荐方向及自动改写方案暂未开放。关键词只筛选已有片库记录，不代表画面分析。文字调整要求会原样加入方案与提示词。

无需登录、API密钥、付款或模型下载。用户片段、说明与方案只在本次浏览器会话内存中使用，不上传、不入公开片库。刷新、结束或离开后清除。不听辨对白，不生成声音。无登录的公开入口不承诺只有本人能访问，各浏览器只处理主动选择的本机文件。

校验：`node --test tests/packaging-core.test.mjs`；CI验证原片库回归、桌面辅助流程、真实对标播放、确认后出提示词和会话清理。实验性模型代码未被辅助版加载，也不参与其运行。

## 认知差：包装与 B 镜参考

[打开完整拉片](https://manman130696-dot.github.io/film-library/reports/cognition-gap/online-report.html)。经用户确认公开，收录 372.9 秒完整轻量预览、22 组包装案例、25 份制作提示词及逐段画面观察。风格方向为深蓝编辑式拼贴、灰阶折面人物与红色重点标记，可用于知识解说的 B 镜。片库与「包装设计」入口均可检索和使用这些案例。

未听辨对白或处理声音；观察段落不等同于穷尽的实拍硬切清单，快速蒙太奇内部切点仍有未逐帧确认范围。
